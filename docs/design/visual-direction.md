# Visual Direction: The Road Has Gone Dark

## Purpose

This document defines the visual identity target for the game's world map and related exploration interfaces.

The goal is not to create a geographic visualisation tool. Generated world data should be transformed into a believable dark fantasy world.

## Core Feeling

The map should feel like:

- an ancient fantasy atlas;
- a world shaped by forgotten history and dangerous places;
- a strategic exploration map where every road, settlement and wilderness area suggests a story.

The player should look at the map and think:

> "I want to explore this place."

## Reference Style

The target sits between:

- hand-drawn fantasy cartography;
- grand strategy world maps;
- dark fantasy exploration interfaces.

It should avoid looking like:

- GIS software;
- scientific terrain visualisation;
- a development/debug viewer.

## Colour Direction

Prefer:

- muted colours;
- parchment/cartographic tones;
- atmospheric contrast;
- clear but restrained terrain differences.

Avoid:

- bright saturated biome colours;
- modern map software aesthetics;
- excessive visual noise.

## Terrain Presentation

Terrain should communicate:

- geography;
- danger;
- atmosphere;
- human settlement patterns.

Mountains should feel like mountain ranges, not isolated elevation markers.

Forests, rivers, roads and coastlines should contribute to the feeling of a lived-in world.

## Settlement Presentation

Settlements are not map points. They represent places.

Visual hierarchy should communicate:

- capitals;
- major cities;
- towns;
- villages;
- ruins or special locations.

Labels should prioritise important locations and avoid overwhelming the player.

## Information Philosophy

The underlying data can be detailed, but the player-facing presentation should reveal information gradually.

The map should answer:

"What is this place?"

before:

"What are all the numerical properties of this cell?"

## Design Principle

Generated data is the foundation, not the final product.

The renderer's purpose is to turn procedural information into a world that feels handcrafted.
