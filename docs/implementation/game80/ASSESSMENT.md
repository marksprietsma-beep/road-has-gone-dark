The brief correctly separates source geography, persistent generated identity and campaign knowledge. Actual cells carry culture/religion/biome/height/neighbor/river/route membership; public markers can support mines. We will aggregate those facts with provenance and cautious cultural wording, not use names as demographic evidence or reproduce vendor military/diplomacy notes.

Reuse GAME-78/79 ContentSeed, Lexicon weighted combinators, declarative compatibility, Rant fact-bound prose, original content, source adapters and all dormant domains. Broad social/political posture is generated background, never a gameplay promise. Memories/traditions remain secondary.

**Compatibility:** retain all GAME-79 compiler/data/vendor/manifest bytes. Add a versioned `profiles-v2` sidecar extension referencing V1. New campaigns pin both; old campaigns keep exactly V1. Missing-only profile creation never overwrites V1, corrupt profiles or campaign pins. No silent migration. New world publication requires both packages. The same native Node helper packages both versions; check exact required manifests before launching. Provide a deterministic development bootstrap and combined export/distribution recipe rather than requiring users to find a CI ZIP.

Use short/full stored summaries in bounded panels at 640×360; preserve keyboard, factual context, map and backtracking. No debug metadata or character/gameplay additions.
