# Original Windows Godot renders

All PNGs are untouched viewport captures from native run [39744145580](https://github.com/marksprietsma-beep/road-has-gone-dark/actions/runs/39744145580), source `a4ac918a18ed58b9e53e86fe6bcd62824cdf567d`. The pointer was moved through Godot before rendering; no pixel processing or synthetic overlays were used. Fixture titles are actual scene labels.

The requested 1280×720 Windows client produced 1280×719; actual sizes and hashes are recorded in [the capture receipt](../evidence/screenshots.json). Other actual sizes are 640×360 and 2560×1440.

At small sizes, scroll the existing power/character panels. The large Lurk view visibly includes Psychic veil and Psychic ambush. The additional small focus capture does **not** prove automatic scroll completion; manual scrolling is still needed. No layout overhaul is claimed.
