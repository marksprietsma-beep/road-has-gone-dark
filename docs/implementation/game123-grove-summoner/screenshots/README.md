`ordinary-` shows actual creation controls. `earned-` uses the real810 XP/total level 10 campaign and its actual250/360 XP entry saves, funded optional advancement and truly committed decline forks. All3 Grove/all 5 Bonded levels are earned. `fixture-` explicitly labels DEVELOPMENT total level 20 and controlled combat states; it never claims earned level20.

Existing long-label/action clipping, scrolling and occasionally hovered tooltips remain visible. Temporary/permanent creature sprites are explicitly labelled humanoid LPC fallbacks.
