## Problem and change

Warlock invocation choices, Binder covenants and later Dragonfire invocations previously reused narrow damage/ward behaviour. Immutable v21 gives these existing classes three distinct, executable choices through the existing rules and tactical authority:

- Warlock: selected at-will movement control or personal concealment/relief; saving-throw counterplay for late blasts and a deliberate late area-control alternative.
- Binder: a permanent, exclusive offensive covenant versus ally intercession. Commitments recover at rest; intercession uses the recipient’s existing reaction to protect an adjacent ally.
- Dragonfire Adept: repeatable elemental breath, a level-six focused/recovery versus wide/resolve decision, and later ally/group invocations with actual different footprints and relief.

Existing combat controls show affected combatants, finite pool capacities and focused-breath recovery. There is no second combat engine, new roster content, migration or production XP grant. Historical packs v1–v20 and frozen GAME-32 tactical source remain unchanged. Only new campaigns default to v21.
