# Original native Windows Godot renders

These 24 PNGs are unmodified viewport captures from the exported game in [Windows release 39882645495](https://github.com/marksprietsma-beep/road-has-gone-dark/actions/runs/39882645495), exact source `e65d098a68858ef9247a7644a94b2485f671a323`. No synthetic overlays or image processing. Actual in-scene labels distinguish development fixtures from earned campaigns.

The requested 1280×720 Windows client rendered at 1280×719; other actual sizes are 640×360 and 2560×1440. See [original dimensions and hashes](../evidence/screenshots.json). Small panels require scrolling. These captures and production-control assertions are technical evidence, not human balance or usability acceptance.

The earned advancement views correctly show 490/640 XP for the next level: the characters are total level 8, not eligible for free advancement to 9. Their already committed histories, including Psychic Warrior 6 / Cognition Adept 2, are in [the earned receipt](../evidence/earned-proof.json).
