# Original native Windows Godot renders

Unmodified viewport captures from the exported game in [the verified native run](https://github.com/marksprietsma-beep/road-has-gone-dark/actions/runs/39972423768), source `239358f1e234059dd4e1a8ca447bf5455e9cd268`. No image compositing or synthetic overlays. Actual scene titles distinguish earned careers from development fixtures.

The requested1280×720 Windows client rendered1280×719; other actual sizes are640×360 and2560×1440. Raw dimensions/hashes are recorded in [the original capture receipt](../evidence/screenshots.json). Tool previews may resize images; the files here retain original pixels.

Earned entry views use actual funded pre-entry saves at640XP/total8→9(Metamind) and250XP/total5→6(Pyrokineticist). The later party earned810XP/total10. Ten-level prestige/total20 views are explicitly development fixtures.

Existing panels need scrolling; compact roster labels can truncate multiclass text. Full names remain in roster tooltips and sheet/history. These captures and actual control assertions do not replace human balance/readability review or resolve GAME89/92/140.
