The priority is two real missing mechanics, then supporting content. Duskblade cannot infer a hit from HP loss (resistance can reduce a real hit to zero), parse a combat log or run a competing attack resolver. RulesRng already emits an attack_resolved result. A synchronous per-thread scoped observer retains that exact existing result while TacticalAuras delegates the one weapon attack to frozen authority. Only a hit then resolves the original spell's effects through RulesEffects. Observation never rolls, rewrites RNG or resolves a contest. Normal/historical attacks return unchanged. Atomic command rejection preserves the original on a downstream effect failure.

Channeling spends one main action and the original spell slot (and original preparation if applicable), including misses/concealment. Critical bonuses belong to the ordinary weapon hit, not a second/doubled spell. The selected original spell must be owned/known, meet requirements and have eligible single-enemy effects. The one equipped proficient melee weapon remains authoritative; bow/natural/suppressed/forged weapons and illegal targets are rejected. Existing one-active-weapon equipment selection is reused. Generated channel deliveries are not counted as new spells.

Spirit Shaman retrieval uses the existing saved selected-spell array and a one-use eligible-rest resource. Initial creation consumes that choice. The existing real home-return rest refreshes one change; committing a different retrieved set consumes it without refilling slots. Opening a screen, a new encounter or process restart does not restore it. Other spontaneous classes still cannot forget learned spells. Multiclass acquisition can make its first selection; later changes require a rest. No new campaign writer, alternate save namespace, XP button or world system.

Both base tracks support1–20 with class skills, HP/BAB/saves, tier resources, spells, feats and deliberate class choices. Abjurant Champion has5levels and Grove Warden3. All prestige is optional, permanently qualified and explicitly XP-funded; none starts at level1 or assigns itself. Their ward/strike and sanctuary/renewal actions function through ordinary budgets/resources.

Supporting original adaptations add Catfolk/Riverborn/Wildborn/Ratfolk with separate heritage/culture/background, sixteen mechanical feats, thirty-two named spell identities (with repeated class references kept separate), ten selected psychic identities, two actual creatures and three body forms. Artwork is the disclosed neutral LPC fallback. Body/equipment/HP/ownership/action/duration authority is reused.
