# Windows playtest

Download the Windows artifact linked in DELIVERY.md. Extract the GitHub artifact ZIP, then extract its inner `game112-character-catalogue-wave-four-windows-x64.zip`. Keep the entire inner folder together and run `road-has-gone-dark.exe`. Do not launch inside either ZIP. Godot and Node installations are unnecessary; the matching helper is bundled.

1. Escape skips the introduction. Use New Game, generate/select a world, choose origin and hometown. Fresh campaigns open the existing creator with v14 automatically. Existing v1–v13 campaigns retain their original options and rules.
2. Try Beguiler, Dragonfire Adept and Marshal in the three party slots. Race/class lists are searchable. Prestige paths must not appear as starting classes. Class, ancestry, culture and background remain distinct.
3. Beguiler: Build → Spells chooses its two initial known spells; Veil of Doubt attacks an enemy's accuracy after a failed Will save, while False Openings gives an ally weapon concealment. Specialisation chooses subtle initiative/concealment or compelling DC/resistance. Spells consume an action and a tier slot.
4. Dragonfire Adept: Specialisation chooses fire/cold/electricity breath and a finite invocation. Breath is repeatable but costs a main action. It affects enemies in a radius-one burst around a legal target, not a cone. Ward/veil/hindrance invocations spend resolve.
5. Marshal: choose a maintained aura. Activating/switching costs a main action and resolve. Allies must remain alive, within three orthogonal tiles and clear sight. War Chanter's earned chorus later reaches four tiles. Stronger same-type bonuses retain normal stacking rules.
6. Try Air/Earth/Fire/Water Genasi and the Highwind/Granite heritage variants. Check inherited numerical adjustments, resistance and finite gifts in Sheet. Changing Intelligence changes the skill budget: use Suggested skill allocation or allocate it explicitly. Suggested class equipment and spells restores a legal class loadout. Ancestry artwork uses the disclosed humanoid fallback.
7. Save each adventurer, inspect all three sheets and choose Party ready. Follow an existing opportunity to a contested site and fight. Movement, targeting, resources, enemy turns and results use the existing tactical engine. Return home, inspect rewards and reload the campaign.
8. To exercise earned prestige, choose Commanding Presence for a Marshal and allocate at least four permanent Performance ranks. Advance Marshal to6 through ordinary rewards. Nine complete four-objective cycles earn360 XP, enough for character level7. At home, explicitly choose War Chanter or continue Marshal. Qualification never assigns a class; the selector grants no XP. The next level then requires490 cumulative XP.
9. Exit and relaunch. Confirm names, ancestry, selected abilities, history, XP and saved resources restore. Eligible home rest deliberately refreshes appropriate resources; application restart alone does not reset Erudite's distinct-power ledger.

Additional paths: Archmage requires permanent level13, Arcana10, Spellcraft10, Greater Spell Focus and genuine tier-seven Wizard/Sorcerer/Beguiler access. Metamind requires level8, INT13, Arcana8, Deep Reserve and permanent manifesting capability. Cognition Adept requires level6, INT13, BAB4, Perception4, Psychic Discipline and manifesting capability. The Advance screen reports other missing requirements; each path must be selected manually with sufficient earned XP.

High-level Archmage/Metamind/Cognition screenshots are labelled development fixtures. Only the separate War Chanter campaign demonstrates360 XP earned through ordinary opportunities. No production XP shortcut is included. All30 base tracks are tested through 20; prestige definitions have their own5/10-level caps and total career limits remain authoritative.

For a defect report, include the source/pin from DELIVERY.md, selected class/ancestry, screen resolution, last action, screenshot and the affected campaign/log files. Keep private world data private unless sharing it intentionally. Earlier unreleased v14 candidate saves require their matching candidate binary; mismatched pins are never silently replaced.
