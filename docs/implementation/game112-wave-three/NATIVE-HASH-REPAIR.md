# Native snapshot repair and earned prestige acceptance

Run38610375101 failed Windows/Linux catalogue restart for all nine advanced Wizard/Psion/Shadowdancer fixture snapshots. The ordinary campaign state reload passed. Saved fixtures and full Linux logs were retained before changing code.

Root cause: `derive_character` normalised the legacy snapshot keys, then appended newer typed fields using dotted Dictionary properties (StringName keys). Mixed String/StringName keys reached canonical sorting. The resulting key order was not lexical: `abilities, action_contract, ancestry, manifesting_level, companions, capabilities, body_form, attributes...`. Hashes therefore differed between native creation and cold restart even though the decoded mechanics were unchanged.

The correction normalises the complete v13 snapshot after every field is added and inserts the hash with a String key. v1–v12 retain their original derivation/hash behaviour. The nine downloaded records produced identical class/resource/stat/ability/equipment values before and after this correction; all nine corrected hashes match ordinary canonical JSON.
