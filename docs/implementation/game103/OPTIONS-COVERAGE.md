# Actual options and compatibility

| Layer | Available now | Qualification |
|---|---|---|
| Ability scores | STR, DEX, CON, INT, WIS, CHA; swap the existing standard array | Real typed GAME-32 modifiers and prerequisites; no duplicated scores or random rolls |
| Mechanical base classes | Roadwarden, Wayfinder, Lantern Adept | All existing base classes exposed; narrative Vanguard/Scout/Adept/Expert remains separate |
| Prestige | Veil Adept | Existing prerequisite-gated authored class; visible while locked; realistic current adventure XP limits access |
| Multiclass | Legal ordered advancement among authored classes | XP-funded at home; existing history retained |
| People | Human, Dwarf, Woodland Elf, Hearth Elf, Smallfolk, Orc, Goblin, Emberkin | Existing prototype examples, explicitly not approved final roster or complete GAME-88 coverage |
| Heritage | One neutral existing mechanical record per current people | No invented bonuses, racial mechanics or new sprite promises |
| Origin and culture | Eligible source-world hometown and its actual culture/region context | Each adventurer can have a different personal origin; party hometown remains the selected campaign anchor |
| Profession/background | Existing source-compatible occupations filtered by actual personal-origin tags | Existing single mechanical hometown-background foundation; professions are narrative/GAME-101 interaction context, not fictitious new stat bonuses |
| Skills/feats | All eight authored skills and five authored feats | Kernel budgets, rank caps, prerequisites and scheduled feat gains; locked reasons visible |
| Equipment | Seven authored equipment entries | Real attack/defence effects and exclusivity; no invented economy |
| Preparations | Granted, currently legal known abilities | Kernel legality; sheet distinguishes current tactical actions from future tactical wiring |
| Character sheet | Saved attributes/modifiers, attacks, defence, saves, initiative, movement/reach, HP/resources, skills, feats, equipment, class history and XP | Reads active encounter HP/resources when opened in combat |

Current V0 tactical controls use attack, movement, guard, spark, slow and healing thread; precision and departure attack are automatic existing rules where applicable. Other authored abilities remain kernel-only and are labelled for future GAME-33 integration. New class choices do not add new tactical buttons or change action economy.

No D&D/Pathfinder option names or rules were copied from the GAME-88 catalogue. Wider classes, prestige paths, ancestries, lineages and acquired conditions remain research/design work. The accepted identity/build/life separation is preserved.
