# First completeness repair: permanent competence with useful skills

The source baseline is v15, including all completed Wave Five gameplay. No new base class is authorised or added.

## Evidence and ranking

1. **Incorrect permanent spell qualification (correct now).** A legally replayed Wizard 13 with INT 12 and Greater Spell Focus receives Archmage eligibility from tier-seven slot capacity, although its owned tier-seven spells fail their actual requirements. The preserved `gap_probe.gd` reproduces this against immutable v15. Capacity is not capability. Add a generic permanent spell-tier requirement for v16, evaluated from the same owned spells, requirements, permanent capacities and spontaneous known choices used by existing authority. Spending slots or changing prepared copies must not erase a permanent qualification; temporary grants and transformations must not supply it.
2. **Five skills without direct gameplay consumers (correct now).** Athletics, Stealth, Acrobatics, Spellcraft and Animal Handling currently serve sheets/prerequisites only in this scan. Add contextual trained approaches to existing opportunities, with explicit time/supply/risk tradeoffs, the same deterministic checks, frozen cycle profiles, existing outcomes and existing single-award XP writer. Do not invent animals or magical world facts. Nature already affects Natural Scholar DC and Performance already affects performance capacity; preserve both rather than misreporting only seven useful skills.
3. **Thin upper-tier spell choices and uneven career variety (separate follow-up).** Some tiers have only two class references, and many martial/pact levels have no newly owned action. Formula scaling, feats and attribute choices mean this is not proof of empty levels. Repertoire identity, target legality and class-specific capstones need dedicated expansion and tactical witnesses, not decorative names.
4. **Prestige compatibility and build guidance (separate follow-up).** The bounded 576-pair search found 485 legal full-cap routes through total level 20. Ninety-one searches lack a completed witness, often because the fixture's chosen casting bridge or default prestige option is unsuitable. This is not an impossibility proof, nor evidence all routes are meaningful single-class careers. Report bridge histories and caps explicitly, and test earned representative entry/decline separately.
5. **Breadth versus verification.** All 760 research occurrences remain accounted for. Definition, source selection, direct effect execution, native packaging and player validation remain separate. Existing neutral humanoid art and unimplemented environmental senses are limitations, not ancestry coverage.

## Boundary and acceptance

Append immutable v16, retaining all v1–v15 bytes and campaign pins. Keep 32 base classes, 18 prestige tracks, 82 feats, 14 skills and the existing world systems. Fresh campaigns select v16; older campaigns keep their exact content. No new save writer, XP policy, combat engine, quest generator or ancestry mechanic.

Verify five new skill approaches through real persisted opportunities, failures and successes, deterministic preview, rank gating, cost/time differences, duplicate-reward rejection and process restart. Verify the Archmage negative/positive permanent gates, spent resources, spontaneous choices, temporary effects, explicit funded advancement and historical v15 behaviour. Twelve representative party members earn their early advancement from ordinary opportunities; high-level and exhaustive catalogue tests are identified as development fixtures. Windows x64 exported execution is required before delivery or merge.

Final candidate refinement: Athletics uses the existing one-turn `quick` event, one provision upfront and DC+2. The initial candidate's four gross provisions minus one cost had the same net gain as the existing free recovery check; the explicit time tradeoff supplies a real difference.
