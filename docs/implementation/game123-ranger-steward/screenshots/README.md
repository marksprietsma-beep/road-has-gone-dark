# Original Windows Godot renders

These original PNGs were rendered by the exported Windows QA executable in [native run 40431423311](https://github.com/marksprietsma-beep/road-has-gone-dark/actions/runs/40431423311), source `2a3262fb73097fa8ce43939b18c7836a50f5cc8a`, pack v32. They are not edited mockups. Exact image hashes and dimensions are in [the native manifest](../evidence/native-capture-screenshots.json).

`ordinary-` shows the actual creator. `earned-` uses the three persistent 490 XP / total level 8 campaign records, including the saved250 XP Ranger 5 optional-entry/decline state. `fixture-` shows explicitly labelled high-level DEVELOPMENT fixtures; it does not claim earned level 20 or earned prestige level 5.

The requested 1280×720 Windows viewport renders 1280×719; filenames and the manifest retain actual dimensions. 640×360 and 2560×1440 are also captured. Existing long-label clipping, scrolling and occasional hovered tooltips remain visible. Companion/summon humanoid LPC art is a documented fallback, not bespoke animal artwork.
