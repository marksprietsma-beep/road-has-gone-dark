1. Extract both ZIP layers, retaining the executable, support/worldgen files, art and credits. Run `road-has-gone-dark.exe`; no installed Godot or Node is needed. Escape skips the intro.
2. Start a fresh world/origin/hometown campaign. Create Duskblade with INT and a melee weapon; select original known spells. Archmage must not appear among initial classes.
3. Prepare the existing party, follow an opportunity/lead and enter combat. Once class3 is earned, select a channel action and click an adjacent enemy. One main action and the original matching slot are paid; misses deliver no spell. With a bow, no slot or a spent action, the button/highlight/click must consistently be unavailable. Ordinary spells compete for the same main action.
4. Earn XP normally and return home to advance. For Archmage, review permanent level13, actual Arcana10/Spellcraft10, focus feat chain and real tier7 access. At1690XP, explicitly choose Archmage for total14, its existing parent casting class and Force or Ward; continuing the base class remains legal.

Later Cleansing/Liberating Wards remove only their listed conditions, never grant actions, slots or resurrection. Casting-suppressed forms cannot use these powers. Rest through eligible home return.
