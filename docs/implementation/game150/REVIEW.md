# GAME-150 Windows review procedure

Use the actual successful package link and inner-ZIP SHA-256 from DELIVERY.md when published. Extract both ZIP layers, keep every support/helper/art/licence file beside the game and launch `road-has-gone-dark.exe`. Neither installed Godot nor Node is required. Escape skips the intro. New campaigns use v23; existing campaigns keep their exact original pins. Never reset an old save to test compatibility.

1. Follow New Game → world → origin → hometown. Create a Wizard, Cleric and a third distinct adventurer. Choose Evocation or Abjuration and Healing or War as permanent career choices. These are class choices, not cultures/deities. At advancement6 the original matching choice is required; a mismatched domain/school is disabled and explained. School/channel reserves are finite and separate from spell slots.
2. Open Characters → Spellbook at home. Edit prepared-copy SpinBoxes and watch each tier's staged copies/daily capacity/current slots. Going over capacity shows OVER and rules reject the save. An insufficient permanent INT/WIS disables the spell and explains its requirement. GUI staging changes no resources. Saving legal home preparations refills the selected prepared-copy allocations but **never** spent shared daily slots. An eligible expedition return/rest restores the daily slots. No selection creates XP.
3. Earn ordinary opportunity XP, return home and use Advance → Commit reviewed level. The native earned example completes49 opportunities for490XP/level8. Tier8 needs casting15 and INT18/WIS18; tier9 needs casting17 and INT19/WIS19. The committed high20/Theurge witnesses are explicitly development fixtures, not claims of earned level20 careers. The shipped game includes no diagnostic executable or XP button.
4. Wizard8 Unweaving tide: choose an enemy group within range6 and clear sight. Radius1 enemies make independent Will saves against removal of sixteen explicitly supported temporary boons. Nearby allies retain their boons. Success saves negate removal but still spend the main action, one tier8 slot and one prepared copy. This widens the existing dispel family; it is not universal antimagic or form/ancestry removal.
5. Wizard9 Stillness lattice: target an enemy; Will negates loss of one main action on its next activation. It does not inflict damage, stop movement or spend the target's shared reaction. The same rules apply if a player is controlled. A prior Concord immunity prevents application; clearing it after the action was already denied does not refund an action. The finite target-activation condition expires normally.
6. Cleric8 Concord of release: target an ally group. Radius1 clears/prevents exactly Stillness lattice, Dissonant seal, Gravitic snare, Slowed and Off Balance for two global round boundaries. It does not heal, grant actions, recover slots or remove arbitrary conditions.
7. Cleric9 Renewing benediction: living radius1 allies heal20 immediately, then12 at their own activation starts while the three-global-boundary boon remains. HP caps apply; downed/dead recipients receive no activation healing. Casting order affects how many activation ticks fit before expiry. No resurrection, extra actions or resource recovery. Unweaving can remove the boon on a failed Will save.
8. At school/domain6, target another ally with Wizard Abjuration/Cleric War. That selected ally receives the ward and class-level temporary HP; the caster receives none unless self-targeted. Existing pinned22 campaigns retain their old caster-buffer behaviour rather than silently changing mechanics.
9. Spend actual spells/reserves in combat, save mid-battle, fully exit and relaunch. Resume the same campaign and inspect identities, ordered history, preparations, remaining copies/slots, HP/statuses and the next legal action. Finish combat and return/rest; only normal victory rewards and the existing rest policy apply.

Native input probes interact with actual production controls and campaign commands; they are not OS mouse automation. Screenshots must be inspected separately from numerical assertions. Long captions, small-layout compromises and tooltip overlap are recorded honestly in SCREENSHOTS.md. Final human balance, a complete tabletop spellbook, deity systems and custom art remain outside this bounded acceptance.
