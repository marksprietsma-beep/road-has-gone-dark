# GAME-69 artwork and icon attribution

Original Batan, Albanes and Thilranlena illustrations are preserved GAME-63
Settlemaker outputs from upstream revision
`d5cf3590cf59e1d382110d25a6910f12507299e2`. The default SettleMaker Symbol
Library is by **barrulus and contributors**, CC BY 4.0 with its explicit rendered-
output exception. That exception covers symbols embedded into maps, including
SVG maps; it does not remove attribution duties when redistributing the asset
library itself. This package contains completed maps, not a reusable provider
symbol library. See the exact [upstream artwork licence](https://github.com/barrulus/settlemaker/blob/d5cf3590cf59e1d382110d25a6910f12507299e2/symbols/LICENSE).
The engine is separately **GPL-3.0-only**. No engine implementation is imported.
Copperline has separate GPL terms and was not used in these original outputs.

The settlement marker shortlist uses the SAME approved **Game-icons family**, by
**Delapouite and Lorc**, [CC BY 3.0](https://creativecommons.org/licenses/by/3.0/),
[game-icons.net](https://game-icons.net/), source revision
`82d948812bfe3f269ef8f731dcdb07b08160edc4`.
`icon-manifest.json` records individual authors, exact source Git blob and SHA-256,
prepared hashes, and the transparent/dark-ink preparation matching project assets.
Original foreground path geometry is retained. No permanent project art replacement.
