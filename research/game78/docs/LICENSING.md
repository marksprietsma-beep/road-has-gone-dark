This matrix distinguishes engine code, raw evaluation output, and shipped content. Repository licensing is not a warranty for every contributed table. Native output files are retained as attributed research evidence, **not approved game content packs**. Do not package `evidence/native` for players.

`vendor/provenance.json` is the adopted-code database: source repository/pin/path, original and transformed SHA, licence, copyright, modification, redistributed status and required notice for every engine file. `vendor/audit-pins.json` describes audited candidates and separate adoption decisions. `tools/vendor-engines.mjs` reproduces the selected transform. Never format vendor files independently: their transformed hashes are pinned.

The two adopted engines total 40 files / 111,977 bytes, before license notices. There is no npm installation or external dependency for the offline content runtime. Build dependencies are locked separately under `tools/build-tools`; Go/.NET/Python only serve native research harnesses. Exact native minimal Venture closure and binary size are measured in `evidence/builds/venture-closure.json`, rather than inferred from total repository size.

`packs/trhgd-expanded-v1.json`, the authored source script, compatibility rules and render patterns are original TRHGD work under repository ownership. This document does not relicense the project wholesale as MIT. CC0 input words remain distinguished from project-authored prose. No GPL/AGPL runtime, online service, SRD prose import, or Eigengrau prose import is introduced.
