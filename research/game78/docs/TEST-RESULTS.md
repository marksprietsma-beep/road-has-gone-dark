## Batch quality and performance

Core-domain structured fact distinctness is 999–1,000 / 1,000 in this same-town batch; origin public prose has **58 SHA / 59 Lexicon duplicates**. Group semantic variants are **127 / 137 out of 200**; names are excluded from those counts. Fixed, Lexicon grammar and Rant renderers consume exactly the same projected facts. Automated checks detect known bad tokens, unresolved grammars, prohibited claims, geography/material conflicts and privacy leaks; they do not certify every sentence's literary quality. [Human review and limitations](HUMAN-REVIEW.md).

Warm in-process measured origin generation: approximately **0.225 ms SHA / 0.242 ms Lexicon per record**, 10,000 trials each. Six-domain town bundles with public rendering: **4.72 / 6.51 ms per town**, 100 trials. One origin record for every **873** visible populated source towns: **270 / 443 ms**, ~**2.69 MB** uncompressed sidecar. Process RSS grew from ~47 MB to ~171 MB during non-streaming benchmark; this includes canonical source/context caches and retained benchmark records, not an isolated vendor allocation. Original pack is **129,977 bytes**; adopted engine code is **111,977 bytes**. These are Linux development measurements, not Windows frame-time promises.

Native upstream output/build evidence is [recorded separately](../evidence/native/). Native default FCG story-hook replay fails because its bank is picked before seeded sampling; controlled-bank replay succeeds. Unsupported FCG magic branches fail and remain recorded. Questify example shutdown reports resources leaked. Those candidates are not adopted player runtimes. No native failure is recast as a passed test.
